EDUPERÚ - CHECKLIST DOCUMENTAL V1

1. Detén npm start si está ejecutándose.
2. Copia/extrae este parche sobre C:\PronabecSOA reemplazando archivos.
3. Ejecuta:
   npm start
4. Abre:
   http://localhost:3000/pages/documentos.html
5. En otra terminal ejecuta:
   npm run documentos:probar

La prueba crea un registro temporal, lo valida, comprueba el listado y lo elimina.
Este parche NO cambia SAGA, seguimiento ni la base de datos.
No sube el archivo físico: registra y valida metadatos personales del documento.
